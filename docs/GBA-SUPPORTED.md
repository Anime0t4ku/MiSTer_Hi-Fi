# GBA Music: confirmed supported games

This list is reserved for named games confirmed to play in **MiSTer Hi-Fi**. No named playback confirmations were included in the supplied baseline, so there are currently no entries.

The previous compatibility document contained only unsuccessful scan results. Its total of successful scans did not identify the games, regions or revisions. A game is not considered confirmed simply because it was absent from that document or uses an MP2K-family sound engine.

When adding a confirmation, record the game title, region/revision, MiSTer Hi-Fi version and a successful playback result. ROM files are not needed for the record.

GBA Music uses the MP2K playback engine. Some games use other sound engines, and a supported game may still have individual songs that do not play correctly.
